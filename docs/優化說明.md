# 網站優化說明

> 分支：`claude/pet-query-app-optimization-wc05w1`　·　Commit：`8f1b0b5`
> 範圍：深色模式、Service Worker 即時更新、PWA/meta 完善、無障礙 (WCAG 2.1 AA)

把 [寵物登記查詢 PWA](https://opopwowo.github.io/pet-query-app/) 做了四大優化,並以 Chromium 實機截淺色＋深色驗證後才推送。

---

## 1. 深色模式 🌗

| 項目 | 說明 |
| --- | --- |
| 跟隨系統 | 預設依 `prefers-color-scheme` 自動切換 |
| 手動切換 | 標頭右上角按鈕,循環 **跟隨系統 → 淺色 → 深色** |
| 記住設定 | 狀態存 `localStorage`(key：`pet_theme`) |
| 無閃爍 | `<head>` 內前置腳本在渲染前先套主題,避免 FOUC |
| 瀏覽器 UI | 依主題動態更新 `<meta name="theme-color">` 與 `color-scheme` |

- 三頁配色以 CSS 變數重構,新增完整深色調色盤。
- 系統主題變動時,若使用者選「跟隨系統」會即時反映。

## 2. Service Worker 即時更新 ♻️

目標:**新版自動偵測 → 提示 → 一鍵套用,不卡舊快取。**

- **導覽(HTML)網路優先**:永遠先拿最新頁面,離線才回退快取。
- **其他同源資源** stale-while-revalidate:先給快取、背景更新。
- 偵測到新版本 → 顯示「✨ 有新版本可用 — 立即更新」提示 → `skipWaiting` + 自動重新整理。
- 首次安裝**不會**誤觸重新整理;套用新版後會清除舊版快取。
- 官方站 `pet.gov.tw` 與外部 CDN 一律走網路,不攔截(不碰登入 Cookie)。

## 3. PWA + meta 完善 📱

- **manifest**：新增 `id`、`shortcuts`(清冊/統計捷徑)、`categories`、`display_override`。
- **三頁補齊**：`manifest` 連結、Open Graph、Twitter Card、多尺寸 favicon、apple / android 加入主畫面 metas、`canonical`。

## 4. 無障礙(WCAG 2.1 AA)♿

- 對比:淺色 + 深色 **40+ 組**文字/背景全部 ≥ 4.5:1(另修掉既有的統計頁貓色、漲跌紅綠、貓別切換白字對比不足)。
- 可見的 `:focus-visible` 外框、「跳到主要內容」略過連結、`prefers-reduced-motion`。
- 圖示按鈕補 `aria-label`、裝飾性 emoji 標 `aria-hidden`、表單欄位補標籤。
- 展開列可鍵盤操作(`role` / `aria-expanded` / Enter / Space);狀態訊息用 `aria-live` 播報。

## 離線可用性 📶

> 前提：先在有網路時開過一次,讓 Service Worker 完成快取。

| 功能 | 離線 |
| --- | :---: |
| 三個頁面(首頁 / 清冊 / 統計)開啟 | ✅ |
| 全國統計圖表(`data/pet-stats.json` 已快取) | ✅ |
| 我的常用晶片號碼(localStorage) | ✅ |
| 名下寵物清冊 — 檢視已匯入資料 | ✅ |
| 深色模式切換、複製晶片號、匯出/還原 JSON 備份 | ✅ |
| **實際查詢**(開始查詢/登入/轉讓/依晶片或飼主查詢) | ❌ 需連線(資料在官方 `pet.gov.tw`) |
| **第一次匯入官方 Excel/CSV**(SheetJS 由 CDN 載入) | ❌ 需連線 |

一句話:**你自己的資料 + 統計 + 介面 → 離線可用;要「查政府的資料」→ 需要網路。**

## 驗證(實際執行,非估算)

- **對比**：以 WCAG 相對亮度公式計算全部色彩配對,淺/深皆通過 AA。
- **Chromium 實機截圖**：三頁 × 淺/深共 6 張,斷言 `data-theme`、`theme-color` 正確,**零 console 錯誤**;手動切深色後重整仍保持。
- **SW 更新端到端**：首次進站不誤觸重整 → 改版後跳更新提示 → 按下重整 → 舊 `v10` 快取清除、只剩 `v11`。
